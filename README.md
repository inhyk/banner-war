# 깃발 전쟁 · BANNER WAR

병사를 소환해 적 성을 부수는 싱글플레이 유닛 전쟁 디펜스. 타워 건설 없이 검병·궁수·기사·마법사·창병·치유사·얼음술사·광전사·명사수·공성포가 자동 전진·공격합니다. 초원·노을·숲·설원·화산 배경의 12개 전장과 전장 선택, 마나 생산 강화 3단계, 적 전체 피해 필살기, 2배속, 일시정지, 효과음, 캠페인 최고 진행 저장을 지원합니다. 외부 에셋이나 서비스는 필요 없습니다.

프로젝트 서버에서 `/play/banner-war`로 실행합니다. 독립 실행:

```sh
python3 -m http.server 5195 --bind 127.0.0.1 --directory public/play/banner-war
```

1–9·0 또는 화면 버튼으로 병사를 소환합니다. Space는 필살기, P/Esc는 일시정지. 창 전환 시 자동 일시정지합니다. 소환 마나와 병종별 재사용 시간이 있으며 아군은 최대 24명. 마나 생산 강화는 70/105/140, 생산량은 초당 12→16→20→24입니다. 필살기는 적 전체에 105 피해, 재사용 28초. 적 AI는 전장 및 전투 시간에 따라 병력을 조합합니다. 적 성 체력이 0이면 다음 전장, 우리 성이 0이면 재도전합니다. 최고 클리어 전장은 로컬 저장하며 저장이 차단돼도 플레이할 수 있습니다.

검증: `node --test games/banner-war/core.test.mjs`. 브라우저: `BANNER_TEST_URL=http://localhost:5195 node games/banner-war/browser-check.mjs`. `window.render_game_to_text()`는 읽기 전용 상태입니다.

추가 병종: 창병은 방어력 무시, 치유사는 아군 24 회복, 얼음술사는 감속, 광전사는 피해량 30% 흡혈, 명사수는 사거리 285, 공성포는 범위 공격과 성에 2배 피해를 줍니다. 전장은 준비·승패 화면에서 선택할 수 있고 전투 중에는 선택이 잠깁니다. 기존 3전장 최고 진행 기록은 유지됩니다. 확장 브라우저 검증은 `node games/banner-war/expansion-check.mjs`입니다.
